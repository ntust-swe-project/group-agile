# Credits

## External assets

None. The game uses no third-party art, audio, fonts or code assets.

- Story 008 (side-view station): the background (space, stars, planet limb,
  station hull), the rooms, stairs and the colonist silhouettes are all drawn
  in code with Godot's 2D drawing calls. Nothing was downloaded, so there is no
  CC0 (or other) licensed asset to list.
- Text uses Godot's built-in default font (Open Sans SemiBold, bundled with the
  engine under SIL OFL 1.1; see Godot's `COPYRIGHT.txt`). The engine itself is
  MIT licensed.

If a CC0 asset is added later (for example by story 009), list it here with its
source URL, author and licence before merging.
